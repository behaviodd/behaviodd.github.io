## 건물번호 하나가 빠져 상품이 반송됐습니다

한 고객이 “주소가 자동으로 바뀌면서 건물번호가 빠진 채 저장됐다”는 내용으로 문의했습니다. 고객감동팀과 물류기획팀이 배송사에 확인했을 때는 이미 배송에 실패해 반송이 시작된 뒤였습니다. 그때 주소를 바로잡아도 상품은 고객에게 도착할 수 없었습니다.

이 사례를 출발점으로 주문서의 배송지 입력 과정을 다시 살펴봤습니다. 고객이 현지 주소를 찾을 수 있는지, 검색 후 무엇을 더 적어야 하는지, 마지막으로 송장에 어떤 주소가 쓰일지까지 확인할 수 있는지가 개선의 기준이었습니다. **메이크스타에서 구매가 가장 많이 발생하는 시장이 중화권과 일본이었기 때문에** 중국 본토·대만·홍콩·일본의 주소 체계를 우선 살폈습니다.

## 1. 중국에서 막힌 주소 검색을 현지 주소 체계에 맞췄습니다

**AS-IS**　기존 주문서는 Google 주소 API에 의존했습니다. 중국 본토에서는 해당 API가 차단되어 고객이 정확한 주소를 알고 있어도 검색으로 기본주소를 채울 수 없었습니다. 검색이 가능한 지역에서도 고객이 주소를 찾는 단서는 달랐습니다. 홍콩에서는 건물명이, 일본에서는 우편번호가 주소를 찾는 출발점이었습니다.

**TO-BE**　배송 국가를 먼저 고르고, 일본우편(Japan Post)의 주소 API처럼 각 국가·지역에서 제공하는 공식 주소 API를 직접 이용하는 방식으로 바꿨습니다. 화면에서는 지역마다 **조회할 수 있는 정보는 선택하거나 자동으로 채우고, 고객만 아는 정보는 따로 입력**하도록 했습니다.

| 국가·지역 | 주소를 찾는 방법 | 고객이 마저 작성하는 정보 |
| --- | --- | --- |
| 중국 본토 | 성을 고르면 해당 시가, 시를 고르면 해당 구·현이 표시됨 | 도로명·번지와 건물·호실 |
| 대만 | 시·현과 구를 고르면 해당 지역의 우편번호가 자동 입력됨 | 도로명·번지·층 등 상세주소 |
| 홍콩 | 도로명이나 건물명으로 검색해 결과를 선택 | 층과 호 |
| 일본 | 7자리 우편번호로 도도부현·시구정촌·지역을 조회 | 번지·건물명·호실 |

첨부 프로토타입에서 일본의 우편번호 조회 화면은 추후 반영안으로 제시했습니다.

## 2. 주소를 입력한 사람에게 송장 표기까지 보여줬습니다

**AS-IS**　주문서에서는 배송지를 어디서 입력하는지, 검색 결과를 선택한 뒤 어떤 항목을 더 적어야 하는지 안내가 부족했습니다. 특히 주소가 영문으로 변환되면 고객이 작성한 내용과 송장에 쓰일 내용 사이에 차이가 생길 수 있었습니다. 건물번호가 빠졌던 고객 사례처럼, 저장이 끝났다는 사실만으로는 배송에 필요한 정보가 모두 담겼는지 알기 어려웠습니다.

**TO-BE**　주문서의 ‘배송지 입력’에서 시작해 저장 후 ‘변경’으로 돌아오기까지 네 단계를 연결했습니다. 입력 중에는 고쳐야 할 항목을 알려주고, 저장 후에는 고객이 가장 잘 아는 건물번호와 호실을 두 표기에서 직접 대조할 수 있게 했습니다.

| 단계 | AS-IS | TO-BE |
| --- | --- | --- |
| 배송지 입력 | 입력을 시작할 위치와 필요한 정보가 불분명함 | 주문서의 ‘배송 정보’ 안에 ‘배송지 입력’ 버튼을 배치 |
| 국가 선택 | 일부 지역은 주소 검색부터 진행하기 어려움 | 배송 국가를 고르면 해당 지역의 입력 항목과 안내를 표시 |
| 주소 입력 | 검색 결과가 어느 항목에 반영됐는지, 무엇을 고쳐야 하는지 파악하기 어려움 | 자동 입력된 주소와 직접 적을 상세주소를 구분하고 누락·형식 오류를 해당 항목 옆에 표시 |
| 저장·확인 | 입력 주소와 송장용 영문 주소가 달라도 알아차리기 어려움 | 주문서에 현지어·영문 주소를 함께 표시하고 ‘변경’으로 다시 수정 |

## 3. 배송·통관 조건을 해당 입력란에서 안내했습니다

**AS-IS**　주소를 정확히 알고 있어도 운송사의 글자 수 제한에 맞춰 어디서 줄을 나눠야 하는지, 통관 시 어떤 이름과 연락처를 사용하는지까지 고객이 알기는 어려웠습니다. 필요한 안내가 입력란과 떨어져 있으면 평소 쓰던 주소와 수취인 정보를 그대로 작성할 수 있었습니다.

**TO-BE**　중국 상세주소는 한 줄에 35자까지 입력할 수 있는 두 칸으로 나눴습니다. 첫 줄에는 도로명과 번지를, 다음 줄에는 건물명과 호실을 적은 예시를 보여줬습니다. 대만에서는 국가를 선택하는 순간 EZ WAY 실명인증 요건을 보여주고, 이름과 전화번호를 적는 칸에는 각각 어떤 등록 정보와 일치해야 하는지 안내했습니다.
